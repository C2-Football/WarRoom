# Playing Vault and Duat with friends

The host needs a free Dynasty HQ email/password account. An invited player can
use a free account or join as a guest. No Sleeper connection or subscription is
required for these games.

The guest option described here requires the guest-access frontend, database
migration and game-function release. It is not available on older releases.

## Before inviting anyone

1. Open the game and choose **With friends** (Vault) or **Play with Friends**
   (Duat).
2. Choose **Sign in / create account**. New hosts select **Create free account**
   and enter their name, email and a password of at least eight characters.
   Returning hosts use the same email/password that created their room.
3. Set the total human players, including yourself. Leave the remaining seats
   controlled by AI if desired.
4. Create the league or campaign, then open its friends/invites panel.

## Send the right invitation

Each human seat or faction has its own **Copy invite** link. Send a different
link to each friend. A link reserves one seat; copying the same link to the whole
group will not create extra seats.

In Vault, use the friend invitation beside each waiting manager. In Duat, open
**Friends & invites** and copy the link for each friend's faction.

## What each friend does

1. Open their invitation in a current browser.
2. Choose one of these paths:
   - **Account:** sign in, or select **Create free account**. The invitation is
     carried through login. Vault opens the assigned seat; in Duat select
     **Join campaign** when prompted.
   - **Guest:** enter a player name and select **Join as guest**. No email,
     password or Dynasty HQ registration is needed.
3. Guests should select **Copy guest pass** and keep it somewhere private. The
   pass controls that seat. Access stays saved in the current browser; on a new
   device, use **Already have a guest pass? → Restore guest seat**. Guest passes
   last 180 days. Losing both the saved browser data and pass prevents recovery
   of that guest seat; a new account does not automatically claim it.

## How the host confirms everyone is in

Look at the player list. Each human seat shows the joined player's name,
**Guest** when applicable, and joined/ready status. A copied link alone does not
mean the person has joined.

- **Vault:** wait for every human seat to show **Joined**, then select **Open
  draft room**.
  Each manager completes their position reveal and readiness steps before the
  draft clock proceeds.
- **Duat:** wait for every human faction to show **Joined**. Each human selects
  **Mark my faction ready**; the host then selects **Open the draft**.

## Returning or troubleshooting

- Account players should sign in with the same account. Their online room list
  contains their joined games. A rejected or expired session offers explicit
  sign-in recovery and pauses shared actions until reconnection.
- Guests can reopen their game in the same browser or restore their private
  pass. Joining as a new guest again is not a replacement for restoring a claimed
  seat. Guests can play their invited seat; hosting and community features use
  an account.
- If an invitation says the seat is already claimed, first reopen the existing
  account or guest seat. Otherwise, ask the host for the intended unused link.
- Finish joining before the draft starts. Once play has started, unclaimed
  invitations are locked.
- If browser storage is blocked or an older browser cannot save guest access
  safely, use an up-to-date browser or sign in with an account.
