# Accepted landing contract and quarantine retirement

The old test required an unused JSON editor schema, four pricing tiers and runtime
editor injection. Current source and the prior owner decision establish that the
accepted landing page is authored directly in HTML. No landing appearance, pricing,
product labels or editor behavior was changed for this correction.

The replacement contract protects actual account-creation routes on the current
origin/project path, returning-user sign-in, the existing upgrade route, local link
destinations, demo-data disclosure, development status and billing accessibility.
The launch browser journey already exercises narrow-phone arrival → real signup
form interaction → confirmed fixture identity → onboarding. This is meaningful
replacement coverage of the current product, not evidence that obsolete editor
requirements passed.

Independent inventory reviewer agreed that replacing the stale contract preserves
the accepted design and the user's current validation requirements. Reviewer
origin-check hardening was incorporated. The runner quarantine is now empty;
final integrated test results must still be obtained. No launch claim from this
change alone.
